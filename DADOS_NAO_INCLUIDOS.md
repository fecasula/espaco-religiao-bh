# Dados não incluídos nesta versão

Esta cópia leve foi preparada sem a pasta `data/` e sem a pasta oculta `.git/`.

Foram preservados os códigos-fonte, arquivos Quarto, aplicação Shiny, configurações,
lockfiles do `renv`, testes, documentação, ativos e saídas renderizadas existentes.

Para executar novamente rotinas que dependem dos dados, restaure a pasta `data/`
a partir da cópia original ou gere os arquivos seguindo a documentação do projeto.

A pasta `.git/` foi retirada apenas para reduzir drasticamente o tamanho do download.
O projeto pode ser adicionado novamente ao controle de versão por clonagem do
repositório ou por uma nova inicialização Git local.
