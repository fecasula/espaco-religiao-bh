# Como contribuir

1. Abra uma *issue* descrevendo o problema, a fonte dos dados e o impacto metodológico.
2. Crie uma branch a partir de `dev`.
3. Não adicione microdados, chaves, endereços residenciais ou arquivos em `data/private/`.
4. Inclua teste automatizado para qualquer alteração em classificação, raio ou cobertura.
5. Atualize `CHANGELOG.md` e a documentação bilíngue quando a mudança afetar resultados.
6. Envie um *pull request* com evidências de renderização e validação.
